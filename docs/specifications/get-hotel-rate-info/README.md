# Get Hotel Rate Info — v5 reference artifacts

These files are copies of the authoritative v5 artifacts published by Sabre
on the Developer Hub. They are **not** generated by us and should be refreshed
from Sabre, not edited in place.

Source: [Get Hotel Rate Info v5 — Resources ZIP](https://developer.sabre.com/rest-api/get-hotel-rate-info/v5/index.html)
(scroll to "Resources" → "GetHotelRateInfo v5.0 Resources").

## Contents

- `schema/GetHotelRateInfoRQ.json` — request JSON Schema.
- `schema/GetHotelRateInfoRS.json` — response JSON Schema.
- `sample-payload.json` — canonical working request and response pair. The
  file is formatted as `REQ-\n{...}\nRES-\n{...}` (not valid JSON as a whole —
  split on the `REQ-` / `RES-` markers).

## Why these live here

Our own OpenAPI spec (`../get-hotel-rate-info.yml`) omits the request/response
examples that Sabre includes in newer APIs (e.g. Hotel Price Check). Until
Sabre ships examples in the OAS, this directory is the closest thing to a
known-good request/response pair.

Notable deltas our mapper should respect, based on the canonical sample:

- Include `"version": "5.0.0"` at `GetHotelRateInfoRQ.version`.
- Prefer `ConvertedRateInfoOnly: false` when you want rates returned under
  `RateInfos.RateInfo`. Default is `true`, which suppresses that branch.
- Supply `RateSource` explicitly (e.g. `"100,113,112,110,130"`) rather than
  relying on the default — defaults may omit the source where inventory lives.
